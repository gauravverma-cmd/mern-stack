RestApi(RestfullApi)

GET /users  - get the user information in Html
GET /api/users - List all users JSON

GET /api/users/1 - Get user with Id 1
GET /api/users/2 - Get user with Id 2

Dynamic path Parameters
GET /api/users/:id 
:id => Variable | Dynamic

POST  /api/users  - Create new user

PATCH /api/users/1 - Edit the user with id

DELETE /api/users/1  - Delete the user with id
